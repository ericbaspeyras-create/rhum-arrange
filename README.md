# Rhum Arrangé

Petite appli pour composer un rhum arrangé maison : volume et degré sur la bouteille, choix des parfums avec voyant d'accord (vert, orange, rouge), méthode (bain-marie ou macération), sucre, puis recette pas à pas.

En ligne : https://rhum-arrange.netlify.app

L'abus d'alcool est dangereux pour la santé. À consommer avec modération.
